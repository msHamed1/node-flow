# NodeFlow LinkedIn video script

Format: 1080 × 1350, 4:5, 30 FPS, approximately 60 seconds, caption-first and silent-safe.

## Sequence

1. **Hook:** Your Node.js architecture changes every day. Your diagrams usually do not.
2. **Idea:** What if the application drew the architecture itself from real executed traffic?
3. **Setup:** Run `npx node-flow dev -- npm run start:dev`.
4. **Reveal:** Exercise the application and watch the runtime map appear.
5. **Architecture:** See routes, controllers, services, databases, caches, queues, and external APIs.
6. **Runtime path:** Follow one executed request from entrypoint to infrastructure.
7. **Perspectives:** Switch between architecture, traffic, latency, and error views.
8. **Waterfall:** Inspect an individual request and see where its time was spent.
9. **Comparison:** Capture before and after snapshots to find architecture drift.
10. **Close:** NodeFlow—see your Node.js architecture execute in real time.

The video uses the real local demo rather than staged product mockups. It contains no generated
usage claims and remains understandable with audio muted.
